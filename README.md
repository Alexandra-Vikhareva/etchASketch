# 🎨 **Etch-a-Sketch Project**
Браузерное приложение для рисования, вдохновленное классической игрушкой Etch-a-Sketch. Проект выполнен в рамках учебного курса [The Odin Project](https://www.theodinproject.com/lessons/foundations-etch-a-sketch).

## ✨ **Возможности**

- **Настраиваемый размер сетки** - регулируемые размеры от 1x1 до 100x100
- **Несколько режимов рисования**:
  - Классический режим - рисование при наведении
  - Радужный режим - случайные цвета
  - Режим затемнения - постепенное затемнение клеток
- **Интуитивное управление** - простой и понятный интерфейс
- **Функция очистки** - быстрый сброс рисунка

## 🎮**Как использовать**
- **Выберите размер сетки** - используйте поле ввода
- **Выберите режим рисования** - нажмите на одну из кнопок режимов
- **Начните рисовать** - наведите курсор на сетку
- **Очистите при необходимости** - используйте кнопку "Очистить"

## 🛠 **Технологии**

-  **HTML5** - семантическая разметка
- **CSS3** - Grid Layout, Flexbox
- **JavaScript (ES6+)** - DOM манипуляции, обработка событий

## 🎯 **Режимы рисования**
### 🖊 **Классический режим**
- Черное рисование на белом фоне
- Простое наведение для создания рисунка

### 🌈 **Радужный режим**
- Каждая клетка закрашивается случайным цветом
- Создает яркие и разнообразные рисунки

### ⚫ **Режим затемнения**
- Клетки постепенно темнеют при каждом наведении
- Создает эффект глубины и тени

## 🎨 **Кастомизация**
### **Размеры сетки**
- Минимальный: 1x1 клетка
- Максимальный: 100x100 клеток

### **Цветовые схемы**
- Черно-белая (классическая)
- Многоцветная (радужная)
- Градиентная (затемнение)
